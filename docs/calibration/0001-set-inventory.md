## 3. 校准发现

1. **主板 sort3「预计市值≥350亿」为笔误**：其余三条件（净利为正、营收≥6亿、现金流≥2.5亿）与现行主板第二套逐字吻合，正确市值门槛为 **50亿**。坐实权威源链（原文 → YAML → 快照仅 trace）。
2. **快照实际反映 2026-04 修订后的规则**：含 2026-04-24 启用的创业板第四套、2024-04 提门槛后的主板（第一套 2亿/1亿、第三套 100亿/10亿）与创业板（第二套 15亿/4亿）值。
3. **表决权差异门槛疑为旧值**：科创板/创业板数据为 100亿 / 50亿+营收5亿（2019/2020 原值），现行或已与主板拉齐（200亿 / 100亿+10亿）——待核。
4. **Excel 规则表 IPO-03 阈值单位笔误**（2026-11-10 补录）：附件《IPO条件测评相关数据.xlsx》`IPO标准规则表 (NEW-OK)` 中 IPO-03 的 check19（3 年经营现金流累计）阈值写 `2.5`，同表其余金额均为元。联查 DB 快照同位置（`mt_ipo_eval_thresold`，std_id=2409424263119896581）实为 `250000000`（2.5 亿）。与 §3-1 的「350亿笔误」属同一套标准（主板第 3 套）的两处独立笔误——Excel 规则表仅作梳理底稿，冲突时以快照为准。归档：`raw/preset_xlsx_20261110/`。
