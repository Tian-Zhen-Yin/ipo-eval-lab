# ADR-0005：校准环节由全人工改为 AI 辅助 + 异构闸门 + 人工签核（D4 修订）

- 状态：Accepted（2026-11-10，R1~R11 拍板）
- 关联：CONTEXT D3/D4、[设计 0003](../design/0003-calibration-pipeline.md)（方案全案）、[calibration/0001](../calibration/0001-set-inventory.md)（错误证据 + 黄金集）、[评审 0003](../reviews/0003-requirement-assessment.md) S6/S9~S11

## 背景

D4 原定「法规原文 → 规则库 YAML（**人工校准**）→ midas 快照（trace）」。校准规模 185 条文 / 64 套条目 / 234 阈值；midas 侧已实锤 5 类数据错误（转写笔误、单位错、旧值残留、序号重复、参数错配），且无机器防线。全人工校准成本高；但 LLM 的错误模式（转写、AND/OR 歧义、幻觉引文）决定了它不能自证——原案「同模型三次投票」对 5 类已知错误零捕获（相关性投票无效，论证见设计 0003 §0）。

## 决策

1. 权威源链修订为：**法规原文 → AI 辅助提取 + 三道异构闸门（L0 确定性 / L1 提取+锚点 / L2 回译）+ L3 快照对照 → 候选库 → 人工签核 → 正式规则库 YAML**；midas 快照降为 trace + 反向差异清单来源。
2. **AI 只在候选库之前活动**；正式库只能由人工签核产生（首批 100% 人核，稳定后按风险分层抽检）。
3. 失败处置 = item 级隔离（evidence pack 进人工队列），批次不中止。
4. 置信度由可验证事实合成（锚点覆盖 / 双通道一致 / 回译 / 快照一致），在黄金集（**复用** calibration/0001 的 43 套 + 已核阈值）上校准，目标黄金集内漏放率 0、误拦率 <10%；**不用模型自报置信度**。
5. 变更维护 v1 = 人工触发重跑管线（条目带 `effective_from` 版本化）；AI 变更影响分析 v2。

## 与 D3 的关系

引擎运行时仍零 AI 依赖。校准管线与第四层叙述 agent 同属「外部 AI 豁免口」：AI 产出规则候选与叙述文本，不参与 run 时判定与计算。

## 后果

- 未决 #5 状态：方案已定（设计 0003），待实现。
- G-A lint 五条归位为 L0 检查项；G-B（#4 窗口单点语义）与之互为表里；G-C/G-D 为校准执行期注记（CONTEXT #5）。
- midas 预置表成为规则库 YAML 的投影视图（导出器，设计 0003 §11）——midas 侧数据质量治理与本项目共用一条管线。

## 被否方案

- 同模型三次投票全过入库、一票否决整批中止（相关性投票无效 + 抖动瘫痪人工队列）；
- 全自动入库无人工签核（正式库必须有人担责）；
- 以 midas 快照为对齐标准/法官（快照自身带错，校准将退化为原样抄库）。
