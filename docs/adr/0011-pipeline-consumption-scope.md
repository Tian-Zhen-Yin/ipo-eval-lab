# ADR-0011：校准管线消费范围封边——按需消费·三段收口

- 状态：Accepted（2026-11-13，用户拍板「按照B来」；底数为 2026-11-13 代码实测的原文库章节统计）
- 关联：[ADR-0005](0005-ai-assisted-calibration.md)（权威源链）、[设计 0002](../design/0002-rulebook-yaml-schema.md)（规则库三段子目录 sets/issuance/positioning）、[设计 0003](../design/0003-calibration-pipeline.md)（校准管线）、[ADR-0009](0009-signoff-tiering-and-two-stage-ingestion.md)（签核分层——规模失控会稀释抽检）

## 背景

原文库五部上市规则共 **2221 条**（2026-11-11 从官方 PDF 抽取）。M1 校准管线目前只消费了约
120 条（43 套上市标准 + 释义条）。「其余 2100 条是否过管线」是 M1 终点线的悬而未决范围决策。

### 事实底数（代码实测，`rulebook/source_texts/` 章节统计）

| 构成 | 条数 | 占比 | 引擎消费方 |
|---|---|---|---|
| 上市标准（各规则「股票上市」章的 3.1.x / 2.1.x 节） | ~120 | 5% | 段③ `sets/`——**已消费闭环** |
| 释义 / 总则（口径定义） | ~23 | 1% | 口径作用域机制（ADR-0010 `caliber_index.py`）——**已消费** |
| 板块定位 / 科创与行业属性条款 | 数十条 | ~2% | 段② `positioning/`——**G-D 待办**（midas IPO-41~61 的 21 套） |
| 段① 发行条件（股本 / 公开发售比例 / 持续经营 / 合规） | **0** | — | 段① `issuance/`——法律源是证监会《首次公开发行股票注册管理办法》，**不在本五部** |
| 退市 / 风险警示 / 重新上市 | ~600 | 27% | **无**（上市后事项；产品是 IPO 上市条件评测） |
| 公司治理（上市后） | ~380 | 17% | **无**（仅 midas check49「无重大权属纠纷」一行与 IPO 时点相关） |
| 信息披露 / 应披露交易 / 停复牌 / 定期报告 / 督导 | ~1100 | 49% | **无**（上市后持续义务） |

需求侧边界：midas 测评四维度（财务 38 套 + 资质 3 + 治理 1 + 板块匹配 21 = 64 套 234 行），
不含退市 / 信披 / 上市后治理。

## 决策

**按需消费（方案 B）：管线只吃引擎有消费方的条款，三段收口，其余章节明文封边不进管线。**

1. **段③ `sets/`**：已完成（28 group / 109 条款，P5 收官）。
2. **段② `positioning/`**：G-D 的 IPO-41~61 板块匹配 21 套逐套映射（实现期待办，数天级）。
3. **段① `issuance/`**：新引证监会《首次公开发行股票注册管理办法》入原文库，精选发行条件
   数十条（股本、公开发售比例、持续经营年限、合规性）；midas 资质/治理 4 行（check49 等）的
   法律锚点在此补齐。
4. **封边清单（下表）**：五部规则同构度高（沪深主板几乎同文、科创/创业同构），按章节类型
   归并封边；漏消费可对照此表追责。

### 封边清单（按章节类型，五部通用）

| 章节类型 | 消费 | 理由 |
|---|---|---|
| 股票上市章·上市条件节（3.1.x / 2.1.x） | ✅ 已消费 | 段③ 主体，43 套闭环 |
| 释义 / 总则 | ✅ 已消费 | 规则级口径（ADR-0010） |
| 股票上市章其余节（上市协议/费用/上市保荐入节部分） | ⛔ 不消费 | 上市程序性事项，非「条件」；midas 无对应测评 |
| 上市保荐和持续督导章 | ⛔ 不消费 | 保荐机构义务，非发行人条件；需求外 |
| 信息披露全族（基本原则/一般规定/定期报告/应披露交易/其他重大事项/行业信息） | ⛔ 不消费 | 上市后持续义务；IPO 时点不存在该义务；需求外 |
| 公司治理章（沪深）/内部治理章（科创） | ⛔ 不消费 | 上市后治理义务；与 IPO 相关的仅 check49 一行，其锚点在段①《注册管理办法》补 |
| 停牌与复牌 / 风险警示 / 退市 / 重新上市 | ⛔ 不消费 | 上市后状态迁移事项；产品边界外 |
| 红筹协调章 | ⛔ 不消费 | 存量监管协调程序；红筹上市条件本体已在段③ 3.1.4/3.1.5 |
| 中介机构 / 日常监管违规 / 申请复核 / 附则 | ⛔ 不消费 | 程序/监管条款，无数值条件可提取 |
| 股权激励 / 重大资产重组 | ⛔ 不消费 | 上市后资本运作；需求外 |

## 被拒方案

- **方案 A（全量 2221 条）**：按现有吞吐实测（133 条 ≈ 2 天含签核），全量 ≈ 5 周纯提取；
  且 midas 无对应行 → L3 全落 source_only → A 档必核预估 1500+ 条，**ADR-0009 的抽检机制在
  此规模下形同虚设**；差异清单爆出数千条噪音淹没真差异。致命伤：1800+ 条退市/信披条款在
  引擎三段结构里**无处安放**——花钱把没人用的条款塞进人工签核链路。法规年更时维护成本
  也是 7 倍（2221 vs ~300）。
- **方案 C（上市章全量折中）**：比 B 多约 2 周换「同章节零遗漏」，但 3.1.x 之外的上市章条款
  （上市协议、费用、程序）与「上市条件」无关，增量收益薄；封边清单已按章节类型逐项给理由，
  遗漏风险有账可查。

## 后果

- M1 终点线就此清晰：段② 21 套映射 + 段① 一部新法规 ≈ 1~2 周，M1 收官。
- 原文库新增法规按「有段位消费方才入库」执行（本 ADR 是准入判据）。
- midas 侧若未来扩测评维度（如退市风险预警），重开本 ADR——封边是范围决策不是永久承诺。
