# ADR-0010：口径的作用域有两级，L2 回译须按作用域判定等价

- 状态：Accepted（2026-11-12，用户拍板「按照推荐的来」；依据 2026-11-12 条款级签核排查）
- 关联：[ADR-0003](0003-metrics-and-five-states.md)（指标与口径绑定）、[设计 0001](../design/0001-top-down-redesign.md) §3.4（专家复核 G4）、[设计 0003](../design/0003-calibration-pipeline.md) §5（L2 回译闸门）、[ADR-0009](0009-signoff-tiering-and-two-stage-ingestion.md)（签核分层）

## 背景

2026-11-12 条款级签核排到 A 档 45 条待签。逐条查实到法规原文后得到三类根因：

| 类别 | 条数 | 现象 |
|---|---|---|
| structure_diff | 38 | midas 把整套叶摊平成一行；`rev_3y_cagr` 用 `gt`；缺 `rev_latest lt` 叶 |
| L2 `partial` | 7 | 渲染文本多带「（扣非前后孰低）」/「（归母）」后缀，模型判「来源外补充」 |
| C 档抽检 | 16 | 闸门全绿 + midas 一致 |

后两类暴露同一件事：**L2 回译的等价前提从未写下来**，规则库的实际口径是「有作用域的」，
模型按「本条自足」判，于是把正确的渲染判成不等价。

### 查实到的两个法律事实

**（一）口径作用域有**两级**：规则级（释义条）与节级（「本节所称 X」）。**

- **规则级**——各规则的释义条对**整部规则**生效：
  - 沪主板/深主板释义条：「净利润…为合并利润表列报的**归属于母公司所有者的净利润**，不包括少数股东损益」；
    「净资产…为合并资产负债表列报的**归属于母公司所有者权益**，不包括少数股东权益」。
  - 科创板 15.1：「净资产，指**归属于母公司所有者**的期末净资产，不包括少数股东权益金额」。
  - 创业板、北交所释义条同款（创业板 12.1、北交所 12.1）。
- **节级**——「本节所称净利润以扣除非经常性损益前后的孰低者为准」仅对**同一节**生效：
  - 沪主板 3.1.2 与 3.1.6 同属第三章**第一节 首次公开发行股票上市** → 3.1.6 的净利润适用该口径。
  - 深主板 3.1.2 / 3.1.6 同节，同理。
  - 创业板 2.1.2 与 2.1.5 同属第二章第一节 → 2.1.2 适用。
  - 北交所 2.1.2 **全条无口径定义**；2.1.3 尾部的「净利润以扣除非经常性损益前后的孰低者为准」
    管的是「前款」（2.1.3 自己的标准），管不到 2.1.2 的净资产条款——但 2.1.2 的净资产受
    规则级释义条约束，「归母」照样成立。

**结论：7 条 L2 `partial` 全部是误判。** 渲染文本的口径后缀在每一处都有原文依据，
判「来源外补充」是因为判定模型按「本条文字须自足口径」理解。

**（二）「以上」的边界。**

- 沪主板 15.3、科创板 15.1 载明「本规则所称以上含本数，超过、少于、低于、以下不含本数」。
- 无论有无该释义条，中文规范文本中「10% 以上」通常含本数。
- 故红筹增长认定的 `rev_3y_cagr ge 0.1` **正确**，midas 的 `gt 0.1` 不精确
  （`gt` 会把恰好 10.0% 的发行人判为不达标——差一个边界点）。

## 决策

### 1. 口径后缀保留，渲染器不改

`items.yaml` 的 `display`（「最近1年净利润（扣非前后孰低）」「最近1年净资产（归母）」）
是全局口径词典，源于专家复核 G4「净利、净资产类一律绑定归母口径，从取数上不可能拿错」。
查实它在**每一处**都有原文依据，故**保留后缀、不改渲染器**。

引擎话术里的口径后缀不是「多说」，是**必须让用户看到**的判定限定——
「孰低」对结果有实质影响，去掉等于把判定条件说错。

### 2. L2 提示词补齐口径作用域前提

L2 判定模型此前按「条级自足」理解——只在本条文字里找口径定义。提示词须显式给出：

> 原文中的口径定义有**两级作用域**：
> ① **规则级**——各规则释义条（「本规则下列用语的具体含义」）对整部规则生效；
> ② **节级**——「本节所称 X」对**同一节（section）内全部条文**生效。
> 判断渲染文本的口径后缀是否有依据时，须按这两级作用域去找，**不得因「本条文字里没有」
> 就判来源外补充**。

同时明确区分两类差异：

- **影响判定结果的差异**（AND↔OR、量词变更、数值/单位错、条件增减、适用主体变化）→ `no`
- **不影响判定结果的表述差异**（口径后缀、术语归一、期间表述归一）→ 修正后应判 `yes`

### 3. 口径作用域是**文档事实**，不进规则库字段

作用域判定依赖「哪条属哪一节」「哪条是释义条」——这是对法规原文的结构性读解，
需要人核，不适合做成运行时自动推断（把法律判断交给代码）。
故作用域只落在 **ADR 与设计文档**里，闸门只做机械执行（提示词前提 + 人工留痕）。

规则库字段只在**取值层**保留口径（`metrics.yaml` 的 `basis: attrib_parent`、
`decision_measure: lower_of_both`），那部分本来就已经在取数上强制，不受本 ADR 影响。

### 4. midas 快照是 trace，不是裁判；快照不精确时不改候选

设计 0003 §6「证人不是法官」原则的具体化：

- `rev_3y_cagr` 快照 `gt` vs 候选 `ge` → **候选正确**，快照不精确。差异记入差异清单，**不回改候选**。
- 快照缺 `rev_latest lt 5亿` 叶（只留 `ge` 一侧）→ 候选完整，快照不全。
- 快照把整套摊平成一行、含 `rev_3y_cagr None` 占位空叶 → 表达粒度差异，值全对。

midas 的口径永远不覆盖法规原文。

### 5. L2 `partial` 的处置：`partial` 不等于「不可用」，也不等于「通过」

设计 0003 §7 行状态表已定：`partial` → 人工队列。本 ADR 补一条：
`partial` 的差异若经查证**仅限口径后缀与术语归一**（即 §2 所述两类），则该条款
**按 `yes` 处理**并补记查证依据；若差异涉及结构/量词/数值，仍走人工裁定。
这不放松闸门——判 `no` 的结构类错误仍拦住入库。

## 后果

- **要做的**：
  1. L2 提示词补两级作用域前提；
  2. 重跑受影响条款的预计算判定，并**留痕**（改判记录进签核记录文件，append-only）；
  3. midas 差异清单增补：4 条 `redchip_listed` 已裁定行 + 上述表达差异；
  4. 38 条 structure_diff + 7 条 L2 复判 + 16 条抽检，批量落签核记录。
- **不做**：不改 items.yaml 的 display；不改渲染器；不回改候选叶值；不放宽结构类闸门。
- **风险**：提示词改动会使 L2 判定结果与历史不可比（部分原判 `yes` 可能变 `partial`）。
  缓解：重跑后逐条比对，只接受**变严**的方向需要复审；`partial`→`yes` 的方向
  必须附查证依据（ADR 本文的两个法律事实），不得无据放行。

## 被否决的备选

1. **把 L2 判 `partial` 的一律放行**——否决。会连带放过 AND/OR、量词类结构错误，
   那正是 L2 存在的唯一理由（设计 0003 §5「最危险的错误类」）。
2. **删掉 items.yaml 里的口径后缀**——否决。G4 的价值在取数层唯一性；
   且「孰低」是判定限定，去掉会让引擎话术把条件说错。
3. **把口径作用域做成规则库字段，渲染器按作用域决定是否输出后缀**——否决。
   作用域要按原文逐节人工核对，做成字段就得维护一张「哪些节有哪个口径」的表，
   且规则库是引擎加载面，不该混入只服务于校准期的渲染细节。
4. **把 midas 快照改成按候选粒度**——否决。快照是外部证据，改造它等于让它失去独立性，
   而它的价值恰恰在于「不同源、可对撞」。
5. **把作用域做成运行时自动推断**——否决。同 3，法律判断交给代码不可接受。
