## 需求范围速览

- 产品：企业经营分析 → IPO直通车（IPO助手），三大块：**IPO条件测评**（本仓库核心）/ IPO主题分析看板+风险巡检（另文档）/ IPO智能体（D3 决策：本项目零 AI 依赖，不在范围）
- 测评流程：新建测评（IPO主体/上市板块/企业类型/报告期3年/所属行业，板块↔类型联动）→ 取数（4 个 ADS 模型 + 企业数据底表）→ 逐项比对（比较符+阈值）→ 四维度评分 → 结果页（下钻/调整重测）→ 测评历史
- 评分规则（文档推演 +「【IPO3】测评报告评分规则」表）：每套标准 100 分 = 达标项数/总项数×100 四舍五入；维度分 = 维度内最高标准分；总分 = 四维度平均。
  ⚠️ **CONTEXT v0.2 已拍板删除计分**（设计 0001 A5），本条仅作原需求记录
- 取数 DSL：`DB / SUM / AVG / PERCENTAGE / CAGR / RAW` + 范围符 `#N`（最近第N年，取 N 年前推的 YYYY-12）/ `~N`（最近N年）；分母≤0 或 CAGR 参数≤0 → `N/A` 且判不达标
- 输出明细粒度：测评项 × 标准一行（指标年 / 计算后指标值 / 差异值 / 差异率 / 达标情况 / AI 分析）
