## 与源数据的刻意差异（更干净，不是更乱）

源快照的 mock 数据本身较松（ytd 与 ptd 不勾稽、部分比率对不上、研发人数>员工数）。
本目录的信号列按会计恒等式重构，**比源更自洽**：

1. ytd 沿季节曲线累计、ptd = ytd 差分（跨年一月重置，源数据 120 对 ytd/ptd 全不勾稽 → 此处全勾稽）
2. 净利 = 税前 − 所得税（营业成本做塞子回归净利锚点，税率≈25%）；营业利润 − 所得税 = 净利总额恒等
3. 扣非 = 归母 × 画像比、非经常 = 差额；毛利率/营业利润率/ROE/ROA/研发强度全部由分子分母重算
4. funds 净额 = 收 − 支、现金余额逐月滚动、货币资金 pe/pb/yb 衔接
5. equity 构成和（股本+公积+未分配）= 归母权益；未分配 pb = 上月 pe；equity_avg 跨表（profitability）同值
6. 研发人数 ≤ 员工数（源数据 7>3 的病态不复刻）

画像的 gm/lev 是**名义值**：塞子校准会让实际毛利率偏离名义值 2~6 个百分点（写入行的比率列
按实际值重算，所以始终自洽）。
